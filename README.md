# DandyLab Ingeniería

Sistema de gestión para instalaciones de maquinaria industrial,
cálculos eléctricos y generación de informes técnicos.

## Funcionalidades

- Gestión de clientes
- Gestión de máquinas
- Registro de instalaciones
- Cálculos eléctricos
- Registro fotográfico
- Generación de informes técnicos en PDF

## Tecnologías

- Python
- Streamlit
- SQLite
- FPDF
